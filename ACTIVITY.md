# Beyond the Prompt: Co-design an AI Lesson Plan Generator

Created by Yi Feng using Google AI Studio. The supplied attribution names Gemini 3 Flash Preview; the current model configuration has not been inspected.

## Audience and purpose

Teacher-facing, cross-disciplinary design for Grades 6–12. Explore how generative AI can support—and sometimes mislead—instructional design by moving from basic prompting to active co-design.

The original activity lists a Google account and laptop/tablet as requirements. Current access, quotas and account eligibility have not been verified.

## Task 1: Shape the generator

Start with the original prompt in `PROMPTS.md`. Choose a pedagogical or usability priority and ask the AI to change the output.

| Priority | Suggested change | Teacher check |
| --- | --- | --- |
| Inclusion | UDL principles and ELL accommodations | Is support specific to the lesson and learner needs? |
| Engagement | Active learning and gamification | Do activities preserve the depth of the content? |
| Visual structure | Table or flowchart | Is the output easier to use during class? |
| Timing | Time-boxed lesson phases | Are preparation, transitions and activities realistic? |
| Technology | Digital tools for interactive tasks | Are access, setup and classroom use feasible? |

Discuss whether the AI's ideas of inclusion and engagement reflect professional teaching experience or remain generic.

## Task 2: Design a critique mode

Ask for a separate tab or side-by-side view that reviews the generated plan using a rubric. The four supplied criteria are alignment, cognitive load, visual clarity and student agency. Participants can add or remove criteria.

Request a 1–5 score per criterion and actionable improvements. The activity does not supply scoring anchors or a validated rubric.

Discuss:

- How does a dedicated critique mode change the relationship with the AI?
- Does a high AI score match the teacher's own judgment?
- Which flaws does the AI miss?
